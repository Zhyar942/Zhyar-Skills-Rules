# Frontend Agent

Build and maintain the customer-facing experience for the fitness application.

- Keep navigation, layout, and interaction quality high

- src/constants/**
- App.tsx

## Tools
- React Native
- Expo
- TypeScript
- React Query / Zustand where relevant

- Clear and polished UX
- consistent spacing and typography
- maintainable reusable component design
- strong, testable user flows

# Autonomous Skills and Plugins Orchestration Rule

When creating, architecting, styling, building, refactoring, or auditing applications, ALWAYS proactively inspect, select, and follow the relevant skills and plugins according to the project's domain and stack:

1. **Frontend & Web Applications**:
   - **Aesthetics & Craftsmanship**: Proactively apply `impeccable`, `oil-ui`, `design-taste-frontend`, `antislop` (`antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`, `antislop-code`), `high-end-visual-design`, `emil-design-eng`, `apple-design`, and `minimalist-ui` to ensure bespoke, non-generic, high-craft interfaces.
   - **Frameworks & Architecture**: Strictly adhere to `nextjs-app-router-patterns`, `tailwind-design-system`, `vercel-react-best-practices`, `gsap-react`, and `modern-web-guidance`.
   - **Animations & Fluid Motion**: Proactively integrate `animate`, `improve-animations`, and `oversized-cursor`.
   - **Quality & Performance**: Enforce `web-design-guidelines`, `web-design-reviewer`, and `chrome-devtools-plugin` (`a11y-debugging`, `debug-optimize-lcp`, `memory-leak-debugging`).

2. **Mobile Development**:
   - **Flutter**: Proactively invoke Flutter plugin skills (`flutter-apply-architecture-best-practices`, `flutter-build-responsive-layout`, `flutter-add-widget-test`, `dart-use-pattern-matching`).
   - **React Native / Expo**: Use `animate-expo`.
   - **Mobile UI Design**: Consult `imagegen-frontend-mobile`.

3. **Backend, Database & Cloud Services**:
   - **Firebase**: Proactively invoke Firebase plugin skills (`firebase-firestore`, `firebase-auth-basics`, `firebase-data-connect`, `firebase-app-hosting-basics`, `firebase-security-rules-auditor`).
   - **Codebase Knowledge Graph**: Use `graphify` for project architecture and structural relationships.
   - **Completeness**: Use `full-output-enforcement` to eliminate truncated placeholders or incomplete files.

4. **Execution Protocol**:
   - Before implementing complex features or creating new apps, inspect the matching skill's `SKILL.md` instructions.
   - Deliver production-grade, anti-slop solutions adhering to the design and architectural patterns established in this knowledge base.

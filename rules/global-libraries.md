## Usage Principles

1. **Global Reusability**: When building or upgrading user interfaces in any project, draw upon the components and styling patterns from these libraries to deliver high-end, responsive, state-of-the-art UI experiences.
2. **Unified Styling**: Ensure designs leverage consistent color tokens, smooth cubic-bezier transitions, double-bezel card architectures, and rich typography.
3. **Vanilla & Modern Framework Compatibility**: The component patterns can be used in React/TypeScript projects via direct imports or adapted cleanly to Vanilla HTML/CSS/JS applications with matched CSS utility classes and SVG/Canvas engines.

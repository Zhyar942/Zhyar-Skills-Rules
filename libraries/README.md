# Enterprise UI Design Systems & Component Libraries

This directory houses the custom design libraries powering the **Production-Ready Furniture Image Scraper Command Center**:

| Library | Paradigm & Aesthetic Focus | Key Components |
|---|---|---|
| **MagicUI** | Dynamic particle effects, kinetic borders, bento grids | `BorderBeam`, `AnimatedBeam`, `Meteors`, `ShimmerButton`, `BentoGrid`, `Marquee`, `BlurReveal` |
| **Uiverse** | Neo-cyberpunk, glassmorphism, tactile glow elements | `CyberCard`, `TacticalSwitch`, `GlowInput`, `HologramBadge`, `NeonMetricCard` |
| **RetroUI** | Monospace terminal, ASCII telemetry, phosphor gauges | `MonospaceTerminal`, `TelemetryFeed`, `RadarGauge`, `MechanicalDial` |
| **ForgeUI** | Industrial hardware controls, raw tactical metrics | `TacticalPanel`, `CyberSlider`, `StatusBeacon`, `DataMatrix` |
| **AnimatedList** | Spring-damped physics queue, kinetic item cascades | `AnimatedList`, `QueueStream`, `SpringTransition` |
| **Uilora** | Ultra-luxury minimalism, frosted glass, satin accents | `GlassCard`, `PillTabs`, `LuxuryHero`, `SmoothDropdown` |
| **UnlumenUI** | Chromatic luminescence, ambient backlighting | `LuminescentGlow`, `DarkAurora`, `AmbientBacklight` |
| **ShmothUI** | Micro-interactions, fluid tab morphing, tooltip physics | `SmoothAccordion`, `LiquidTabBar`, `InteractiveTooltip` |
| **AnimateUI** | SVG flowlines, live network topology pulse animations | `NodeConnector`, `PulsingNode`, `WaveformGraph` |
| **VengenceUI** | Threat indicators, alert strobes, DMCA purge modal | `CyberAlert`, `DangerModal`, `TakedownStrobe` |
| **SkiperUI** | High-velocity facet filters, rapid keyboard-driven controls | `QuickFilterChip`, `SkipStepPill`, `FastSearchBar` |
| **AnimasterLib** | Perceptual dHash bit matrix visualizer, comparison sliders | `PerceptualMatrixVisualizer`, `SplitImageSlider`, `CanvasParticleBackground` |
